```bash

```

### 2️⃣ **تشغيل التطبيق**


## 📱 دليل الاستخدام

### 👨‍🎓 **إدارة الطلاب**

#### **تسجيل طالب جديد:**
1. اذهب إلى "الطلاب" → "إضافة طالب جديد"
2. املأ البيانات الشخصية (عربي وإنجليزي)
3. أدخل بيانات الاتصال والعنوان
4. اختر المؤسسة التعليمية
5. أدخل البيانات الأكاديمية
6. حدد الرسوم ونسبة الربح
7. احفظ البيانات

#### **البحث عن طالب:**
1. استخدم شريط البحث في الأعلى
2. ابحث بالاسم أو رقم الجواز
3. انقر على النتيجة للوصول لتفاصيل الطالب

#### **تعديل بيانات طالب:**
1. اذهب لتفاصيل الطالب
2. انقر "تعديل البيانات"
3. عدل المعلومات المطلوبة
4. احفظ التغييرات

### 🏢 **إدارة المؤسسات**

#### **إضافة مؤسسة جديدة:**
1. اذهب إلى "المؤسسات التعليمية"
2. انقر "إضافة مؤسسة جديدة"
3. املأ بيانات المؤسسة
4. اختر النوع والبلد
5. احفظ البيانات

### 💰 **إدارة المدفوعات**

#### **إضافة مدفوعة:**
1. اذهب إلى "المدفوعات"
2. انقر "إضافة مدفوعة جديدة"
3. اختر الطالب
4. أدخل المبلغ والتفاصيل
5. احفظ المدفوعة

### 📁 **إدارة المستندات**

#### **رفع مستند:**
1. اذهب لتفاصيل الطالب
2. انقر "رفع مستند"
3. اختر نوع المستند
4. اختر الملف (حد أقصى 16MB)
5. ارفع المستند
