## 🆕 الميزات الجديدة في هذا الإصدار

### 🤝 نظام إدارة الوكلاء الشامل
- **إضافة حقل الوكيل**: يمكن تسجيل اسم الوكيل الذي جلب الطالب
- **نسبة العمولة**: تحديد نسبة عمولة مخصصة لكل وكيل (مثال: 5%)
- **حساب العمولة التلقائي**: يتم حساب مبلغ العمولة تلقائياً عند إضافة المدفوعات
- **تقارير الوكلاء**: تقارير شاملة تظهر:
  - عدد الطلاب لكل وكيل
  - إجمالي العمولة لكل وكيل
  - متوسط العمولة لكل طالب
  - إجمالي عمولات جميع الوكلاء

### ⏱️ نظام إدارة مدة الدراسة
- **مدة الدراسة بالأشهر**: تسجيل مدة الدراسة المتوقعة
- **تحويل تلقائي**: عرض المدة بالسنوات والأشهر
- **تتبع الفترات**: مراقبة فترات الدراسة للطلاب

## 🛠️ التثبيت والتشغيل

### متطلبات النظام
- Python 3.8 أو أحدث
- Flask
- SQLAlchemy
- Bootstrap 5
- Font Awesome

### خطوات التثبيت

1. **تثبيت المتطلبات:**
```bash
pip install -r student_requirements.txt
```

2. **تشغيل النظام:**
```bash
python run_student_app.py
```

3. **الوصول للنظام:**
- الرابط المحلي: http://localhost:5001
- الرابط على الشبكة: http://[your-ip]:5001

## 🎯 كيفية استخدام نظام الوكلاء

### إضافة وكيل جديد
1. عند تسجيل طالب جديد، أدخل اسم الوكيل في الحقل المخصص
2. حدد نسبة العمولة للوكيل (مثال: 5%)
3. أدخل مدة الدراسة المتوقعة بالأشهر
4. سيتم حساب مبلغ العمولة تلقائياً عند إضافة المدفوعات

### عرض تقارير الوكلاء
1. اذهب إلى صفحة "التقارير"
2. ستجد قسم "إحصائيات الوكلاء" يعرض:
   - إجمالي عمولات جميع الوكلاء
   - عدد الوكلاء النشطين
   - تفاصيل كل وكيل (عدد الطلاب، إجمالي العمولة، متوسط العمولة)
