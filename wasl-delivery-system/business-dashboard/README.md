# 🏢 لوحة تحكم المشاريع - Wasl Business Dashboard

> لوحة تحكم ويب للمشاريع والشركات في نظام وصل للتوصيل

---

## 💼 نظرة عامة

لوحة تحكم ويب للمشاريع تتيح لهم:
- 📊 متابعة الطلبات والإحصائيات
- 📦 إدارة الطلبات
- 🚗 متابعة السائقين
- 💰 التقارير المالية
- 👥 إدارة الحسابات
- 📈 تحليلات الأداء

---

## 🚀 البدء السريع

### المتطلبات
- Node.js 16+
- npm أو yarn

### التثبيت

```bash
# تثبيت المكتبات
npm install

# تشغيل التطبيق
npm start
```

---

## 📦 التقنيات المخططة

- **React** - مكتبة واجهة المستخدم
- **Next.js** - إطار العمل
- **TypeScript** - لغة البرمجة
- **Tailwind CSS** - تنسيق الواجهة
- **Chart.js** - الرسوم البيانية
- **Axios** - طلبات HTTP
