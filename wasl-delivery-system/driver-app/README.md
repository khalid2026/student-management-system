# 🚗 تطبيق السائقين - Wasl Driver App

> تطبيق React Native للسائقين في نظام وصل للتوصيل

---

## 📱 نظرة عامة

تطبيق موبايل للسائقين يتيح لهم:
- 📋 استقبال طلبات التوصيل
- 🗺️ تتبع المواقع والمسارات
- ✅ قبول/رفض الطلبات
- 📍 تحديث الموقع الحالي
- 💰 متابعة الأرباح
- ⭐ عرض التقييمات

---

## 🚀 البدء السريع

### المتطلبات
- Node.js 16+
- npm أو yarn
- Expo CLI
- Expo Go (للتجربة على الهاتف)

### التثبيت

```bash
# تثبيت Expo CLI
npm install -g expo-cli

# تثبيت المكتبات
npm install

# تشغيل التطبيق
npm start
```

---

## 📦 المكتبات المستخدمة

- **React Native** - إطار العمل الأساسي
- **Expo** - أدوات التطوير
- **React Navigation** - التنقل بين الشاشات
- **Axios** - طلبات HTTP
- **AsyncStorage** - تخزين البيانات
- **React Native Maps** - الخرائط
- **Expo Location** - تتبع الموقع
