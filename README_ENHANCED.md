# 🎓 نظام إدارة الطلاب المحسن مع الوكلاء ومدة الدراسة - خالد سوفت

نظام شامل ومتطور لإدارة الطلاب مع إضافة مميزات جديدة للوكلاء ومدة الدراسة والحسابات المالية المتقدمة.

## 🆕 **المميزات الجديدة المضافة**

### 👥 **إدارة الوكلاء (Agent Management)**
- ✅ **إضافة وإدارة الوكلاء** الذين يحضرون الطلاب
- ✅ **نسبة عمولة مخصصة** لكل وكيل (افتراضية وقابلة للتخصيص)
- ✅ **ربط كل طالب بوكيل** مع حساب العمولة تلقائياً
- ✅ **إحصائيات الوكلاء** (عدد الطلاب، إجمالي العمولات)
- ✅ **عرض تفصيلي للوكلاء** مع معلومات الاتصال والأداء

### ⏰ **مدة الدراسة (Study Duration)**
- ✅ **تحديد مدة الدراسة** بالشهور أو السنوات
- ✅ **مرونة في التحديد** (من شهر واحد إلى عدة سنوات)
- ✅ **عرض مقروء** لمدة الدراسة في جميع التقارير
- ✅ **تتبع البرامج الدراسية** المختلفة

### 💰 **النظام المالي المحسن**
- ✅ **حساب تلقائي للعمولات** بناءً على نسبة الوكيل
- ✅ **الربح الصافي** بعد خصم عمولة الوكيل
- ✅ **عرض مفصل للبيانات المالية** في كل طالب
- ✅ **إحصائيات مالية شاملة** للوكلاء والأرباح

### 🎨 **واجهة محسنة**
- ✅ **تصميم جديد** مع ألوان متدرجة جذابة
- ✅ **كروت تفاعلية** لعرض الطلاب والوكلاء
- ✅ **إحصائيات بصرية** في لوحة التحكم
- ✅ **تجربة مستخدم محسنة** مع تأثيرات بصرية

## 📊 **هيكل قاعدة البيانات المحسن**

### **جدول الوكلاء (Agents)**
```sql
- id: المعرف الفريد
- name: اسم الوكيل
- phone: رقم الهاتف
- email: البريد الإلكتروني
- address: العنوان
- default_commission: نسبة العمولة الافتراضية (%)
- is_active: حالة الوكيل (نشط/غير نشط)
- notes: ملاحظات
- created_at: تاريخ الإضافة
```

### **جدول الطلاب المحسن (Students)**
```sql
# الحقول الجديدة المضافة:
- study_duration_value: قيمة مدة الدراسة (رقم)
- study_duration_unit: وحدة مدة الدراسة (months/years)
- agent_id: معرف الوكيل المسؤول
- agent_commission_percentage: نسبة عمولة الوكيل (%)
- agent_commission_amount: مبلغ عمولة الوكيل ($)
```

## 📋 **دليل الاستخدام**

### ➕ **إضافة طالب جديد مع الوكيل:**
1. اذهب إلى "تسجيل طالب جديد"
2. املأ البيانات الشخصية والأكاديمية
3. **حدد مدة الدراسة** (القيمة والوحدة)
4. **اختر الوكيل المسؤول** من القائمة
5. **حدد نسبة عمولة الوكيل** (أو استخدم الافتراضية)
6. أدخل الرسوم الدراسية ونسبة الربح
7. **سيتم حساب العمولة والربح الصافي تلقائياً**
8. احفظ بيانات الطالب

### 👥 **إدارة الوكلاء:**
1. اذهب إلى "إدارة الوكلاء"
2. اضغط "إضافة وكيل جديد"
3. أدخل بيانات الوكيل ونسبة العمولة الافتراضية
4. احفظ بيانات الوكيل
5. **عرض إحصائيات كل وكيل** (عدد الطلاب، العمولات)

### 📊 **عرض الإحصائيات:**
- **لوحة التحكم**: إحصائيات شاملة للطلاب والوكلاء والأرباح
- **صفحة الطلاب**: عرض تفصيلي مع الوكيل ومدة الدراسة
- **صفحة الوكلاء**: أداء كل وكيل وعمولاته
